# The stack

__In this chapter the libraries used will be discussed. Not all of these were actually used, but ideally they would be if the project was finished.__

## Jecs
Jecs is an ECS library.

## Replecs
Replecs is a replication library, built to work with Jecs.

## ProfileStore
Profilestore is a wrapper around Roblox datastores. It makes doing datastores miles easier, although using an ECS in combination with it is kinda hard.

## Other libraries
Here are listed some libraries which could be implemented, but aren't all that necessary for finishing the final product.

### Roact
Roact is a GUI library. It makes it so GUI elements can be declared through code, which I like the idea of a lot more than messing around with GUI objects in the Roblox Studio explorer.

### Axis
Axis is an input library.
